An entry for [make.fun](https://make.fun/bounty/news-image-20261120)'s "Sum up 20 November's world news in one image" bounty ($250 in USDC): a newspaper front page summing up Friday 20 November 2026 — overnight Russian ballistic-missile strikes on Kyiv and the damaged Dnipro bridges, Friday's deepening AI stock sell-off across Asia, the world court's Myanmar genocide ruling, the aftermath of the first Trump–Xi–Putin summit, Anthropic's record IPO, the Iran war and Hormuz tanker attacks, the Houthi strike on Riyadh, Cyclone Akvan nearing India, and more.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) copies the bundled `entry.png` to the output directory. The image itself is drawn by `make_image.py` (PIL) with no external images and no network.
